# Subtopic 6: Ketaksamaan Linear — Best Examples

## MCQ, Difficulty 1
```sql
(6, 'mcq',
 'Selesaikan: 2x - 1 ≤ 9',
 '["A. x ≤ 4", "B. x ≤ 5", "C. x ≤ 8", "D. x ≤ 10"]',
 'B',
 'Langkah 1: 2x ≤ 10.\nLangkah 2: x ≤ 5.\nJawapan: x ≤ 5',
 1)
```

## Short, Difficulty 2
```sql
(6, 'short',
 'Cari integer terbesar yang memenuhi: 3x < 20',
 NULL,
 '6',
 'Langkah 1: x < 20/3 = 6.67.\nLangkah 2: Integer terbesar < 6.67 ialah 6.\nJawapan: 6',
 2)
```

## MCQ, Difficulty 3
```sql
(6, 'mcq',
 'Jika -2x > 6, maka:',
 '["A. x > -3", "B. x < -3", "C. x > 3", "D. x < 3"]',
 'B',
 'Langkah 1: Bahagi kedua-dua belah dengan -2.\nLangkah 2: Terbalikkan tanda ketaksamaan: x < -3.\nJawapan: x < -3',
 3)
```

## MCQ, Difficulty 3
```sql
(6, 'mcq',
 'Selesaikan: -1 < 2x + 3 ≤ 9',
 '["A. -2 < x ≤ 3", "B. -1 < x ≤ 6", "C. 1 < x ≤ 6", "D. -4 < x ≤ 6"]',
 'A',
 'Langkah 1: Tolak 3 pada semua bahagian: -1 - 3 < 2x ≤ 9 - 3 → -4 < 2x ≤ 6.\nLangkah 2: Bahagi dengan 2: -2 < x ≤ 3.\nJawapan: -2 < x ≤ 3',
 3)
```
